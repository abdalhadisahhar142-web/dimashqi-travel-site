# الدمشقي للسياحة والسفر وخدمات العمرة

موقع المكتب: HTML و CSS و JavaScript فقط، بدون أي مكتبات أو أدوات بناء.

## الملفات

```
index.html     محتوى الموقع
style.css      كل التنسيقات (مقسّمة لأقسام مرقّمة)
script.js      كل الحركة والتفاعل (مقسّم لأقسام مرقّمة)
images/
  logo.png              اللوغو الأصلي (برتقالي)
  logo-white.png        اللوغو أبيض بخلفية شفافة (الفوتر)
  logo-icon-white.png   أيقونة اللوغو بدون الكتابة (الهيدر)
  favicon.png           أيقونة المتصفح
```

## التشغيل

افتح `index.html` بالمتصفح مباشرة. للنشر ارفع المجلد كما هو على أي استضافة.

## الصور

صور الوجهات من Unsplash (مجانية للاستخدام التجاري) وبتنحمّل من سيرفرات Unsplash، فلازم يكون في إنترنت لتظهر.
كل الصور معرّفة بمكان واحد: `script.js` القسم 3 (`PHOTOS`)، وصور الهيرو و"رحلتنا بالصور" ودمشق بالليل بـ `index.html`.
لتستعمل صورة من عندك: حطها بمجلد `images` واكتب مسارها بدل الرقم، مثلاً `"images/umrah.jpg"`.

## تعديل المحتوى

| بدك تعدّل                         | وين                                                   |
| --------------------------------- | ----------------------------------------------------- |
| رقم الواتساب أو الهاتف أو العنوان | `script.js` القسم 2، و `index.html` (الفوتر و Schema) |
| الرحلات والأسعار والوجهات         | `script.js` القسم 3 (`PACKAGES`، `LOCAL_TRIPS`)       |
| آراء العملاء                      | `script.js` القسم 3 (`TESTIMONIALS`)                  |
| الألوان والخطوط                   | `style.css` القسم 1                                   |
| قسم موقعنا والخريطة               | `index.html` قسم `<!-- Location -->`                   |
| صور معرض الوجهات                  | `script.js` القسم 4 (`GALLERY_SLIDES`)                |

- آراء العملاء حالياً نماذج. بعد ما تحط تقييمات حقيقية، غيّر `TESTIMONIALS_ARE_SAMPLES` إلى `false`.
- قيمة `destination` بكل رحلة لازم تطابق خيار من قائمة الوجهات بفورم الحجز، لتنختار تلقائياً لما الزبون يكبس على الرحلة.
- فورم الحجز بيجهّز رسالة واتساب للمكتب فيها اسم الزبون ورقمه والوجهة.
